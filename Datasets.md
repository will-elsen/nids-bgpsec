# Datasets

Every dataset in this assignment is generated by the lab itself: a private RPKI, six routers, and the BGP messages they exchange. None of it is connected to the real internet or the real RPKI. Each section names the `labkit` calls that read it; the [Containerlab guide](Containerlab.md#3-labkit-the-notebooks-driving-library) documents the calls themselves.

#### The lab RPKI, served over RTR

The lab runs its own RPKI: a certificate authority (**Krill**) issues one ROA and a router certificate for each AS, a publication point (**rsyncd**) serves them, and a validator (**Routinator**) checks the certificate chains and hands the result to the routers over the RPKI-to-Router protocol (RTR, [RFC 8210](https://www.rfc-editor.org/rfc/rfc8210.html)). Routers never see certificates, only the validated payloads below.

How to reach it: `lab.rtr_dump()` returns one text line per PDU, exactly as a router would receive them; `lab.vrp_count()` and `lab.router_key_count()` count them; `lab.skis()` reads the same SKIs from the lab's key vault on disk, as a `{ASN: SKI}` dictionary.

**IPv4 Prefix PDU** — one Validated ROA Payload (VRP), printed as `PDU IPv4 Prefix    10.64.2.0/24-24 => AS64602 (announce=1)`

| Name | Type | Description |
| --- | --- | --- |
| prefix | IPv4 prefix | the address block the ROA covers |
| max length | integer | the longest prefix length the origin may announce |
| ASN | integer | the AS authorized to originate the prefix |
| announce | flag | 1 when the VRP is being added, 0 when withdrawn |

**Router Key PDU** — one BGPsec router key, printed as `PDU Router Key     AS64602  SKI <40 hex digits>  SPKI <n>B`

| Name | Type | Description |
| --- | --- | --- |
| ASN | integer | the AS the key may sign for |
| SKI | 20-byte hex string | Subject Key Identifier: the SHA-1 hash that names this key in signatures |
| SPKI | bytes | the public key itself (only its length is printed) |

#### Router path records

What each router believes about the lab's prefix, `10.64.2.0/24`, with both validation results. Four routers run QuaggaSRx; the far-end observer, AS64605, runs GoBGP-SRx and reports the same fields.

How to reach it: `lab.routes(node)` returns every path a router holds as a list of `Route` records; `lab.best(node)` returns the one in use (or `None`); `lab.show(node)` prints them one per line. Node names are `lab.VICTIM` (AS64604), `lab.OBSERVER` (AS64605), and `as64601`–`as64604`, `as64666`.

| Name | Type | Description |
| --- | --- | --- |
| as_path | list of integers | the AS_PATH, nearest AS first, origin last |
| peer | string | the neighbor address the path was learned from |
| origin_state | string | route origin validation result: `valid`, `invalid`, `notfound`, `undefined`, or `-` (off) |
| path_state | string | BGPsec path validation result, same values |
| localpref | integer | local preference after policy adjustments |
| localpref_base | integer | local preference before policy adjustments |
| localpref_delta | integer | the adjustment policy applied |
| best | boolean | true for the path the router is using |
| ignored | boolean | true when policy dropped the path |
| signed | boolean | true when the path arrived with a `BGPsec_PATH` attribute |
| segments | list of (ASN, SKI) | one entry per signature, newest signer first; empty for unsigned paths |

#### BGPsec_PATH captures

Raw BGP packets captured on one inter-AS link, with the `BGPsec_PATH` attribute dissected out of each UPDATE.

How to reach it: `lab.capture(node, iface)` writes a pcap under `containerlab/lab/phase4/captures/` and returns its path; `lab.dissect(pcap)` returns one `Signed` record per `BGPsec_PATH` seen; `lab.signature_growth()` captures all four links in turn and returns `(link label, hops, signatures)` per link, origin outwards.

| Name | Type | Description |
| --- | --- | --- |
| secure_path | list of integers | the Secure_Path: one ASN per AS that carried the route |
| skis | list of hex strings | the Signature_Block: the SKI on each signature |
| sig_lengths | list of integers | the length in bytes of each signature |
| hops | integer | number of Secure_Path entries |
| signatures | integer | number of signatures |
